Chinese HSK Offline Android — v1.8.0 feature report

Added:
- Settings screen reachable from dashboard.
- Per-user subtitle defaults: Pinyin and Turkish can be Auto / Always On / Off.
- Default autoplay preference.
- Persistent default speech speed (0.75x–1.25x).
- Configurable daily review target (5–30 vocabulary cards).
- Purple / Dark / Light appearance selection stored locally.
- Progress overview with total mastery, HSK-by-HSK progress, vocabulary/sentence exam averages, placement result, and favorite count.
- Local backup export to one JSON file using Android Storage Access Framework (no storage permission).
- Local backup restore for progress, favorites, scores, placement and settings.
- Daily Review now respects the configured card target.
- Scene player reads Pinyin/TR and autoplay defaults from Settings.
- GitHub app-flow validation extended to settings/backup requirements.

Unchanged safeguards:
- 300/300 scenes, 30,000 dialogue turns, 2,400 flash cards.
- Vocabulary exam threshold >=90%, sentence exam threshold >=85%.
- Next scene remains locked until both exam stages pass.
- Offline-first behavior and local progress persistence.
