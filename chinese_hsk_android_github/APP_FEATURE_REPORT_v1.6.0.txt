Chinese HSK Journey v1.6.0

OFFLINE VOICE CACHE
- Authored packaged audio remains first priority.
- When authored audio is absent, the app scans locally installed Mandarin TTS voices.
- Each stable Voice Bible profile is deterministically bound to one local offline Mandarin voice and that binding is persisted.
- A dialogue/narrator line is synthesized once into app-private local storage and reused on later playback.
- Playback speed is applied during playback, so a separate cached file is not needed for 0.75x/0.85x/1.0x/1.15x/1.25x.
- Cache automatically prunes oldest files above approximately 350 MB.
- If synthesize-to-file fails, direct offline TTS remains the final fallback.
- No cloud/network TTS fallback is intentionally used by this layer.
